# Non-Linear Data Structure (Assessment 3.3)

Python (PyCharm) program. Each structure is in its own file:

- `binary_tree.py` - Binary Tree with BFS and DFS (runnable by itself)
- `graph.py` - Graph with BFS and DFS (runnable by itself)
- `main.py` - asks for your last name, then runs both

Run: open the folder in PyCharm and run `main.py` (or run either structure file alone).

Expected output:
- Binary Tree BFS: R -> E -> P -> U -> N -> T -> E
- Binary Tree DFS: R -> E -> U -> N -> P -> T -> E
- Graph BFS: R -> E1 -> P -> U -> N -> T -> E2
- Graph DFS: R -> E1 -> U -> N -> P -> T -> E2
